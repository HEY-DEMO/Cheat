# Naming Conventions

> **Category**: `coding-standards` · **Last Updated**: `2026-09-21` · **Difficulty**: `Beginner`

---

## TL;DR

Consistent naming improves readability and reduces cognitive load. Pick a convention per language and enforce it with linters.

---

## 🔑 Common Conventions

| Style          | Example             | Used For                                |
|----------------|---------------------|-----------------------------------------|
| `camelCase`    | `getUserName`       | JS/TS variables, functions              |
| `PascalCase`   | `UserService`       | Classes, components, types              |
| `snake_case`   | `get_user_name`     | Python functions, variables             |
| `UPPER_SNAKE`  | `MAX_RETRY_COUNT`   | Constants across most languages         |
| `kebab-case`   | `user-profile`      | URLs, file names, CSS classes           |
