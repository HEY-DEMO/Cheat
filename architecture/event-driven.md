## TL;DR

Event-Driven Architecture (EDA) uses events as the primary mechanism for communication between decoupled services, enabling reactive, scalable systems.

---

## 📋 Overview

- **What**: A pattern where services emit and consume events asynchronously.
- **Why**: Extreme decoupling, natural audit trails, high throughput.
- **When**: Real-time data pipelines, CQRS/Event Sourcing, IoT, financial systems.
