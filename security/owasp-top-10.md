## TL;DR

The OWASP Top 10 is the industry-standard list of the most critical web application security risks. Know them, test for them, and defend against them.

---

## 🔑 The Top 10 (2021 Edition)

| #   | Risk                                    | Key Mitigation                               |
|-----|-----------------------------------------|----------------------------------------------|
| A01 | Broken Access Control                   | Enforce least privilege, deny by default     |
| A02 | Cryptographic Failures                  | Use strong algorithms, manage keys properly  |
| A03 | Injection                               | Parameterized queries, input validation      |
| A04 | Insecure Design                         | Threat modeling, secure design patterns      |
| A05 | Security Misconfiguration               | Hardened defaults, automated config audits   |
| A06 | Vulnerable & Outdated Components        | Dependency scanning, regular updates         |
| A07 | Identification & Authentication Failures| MFA, secure session management               |
| A08 | Software & Data Integrity Failures      | Code signing, CI/CD pipeline security        |
| A09 | Security Logging & Monitoring Failures  | Centralized logging, alerting                |
| A10 | Server-Side Request Forgery (SSRF)      | Input validation, network segmentation       |
