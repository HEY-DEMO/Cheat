# Hash Maps

> **Category**: `data-structures` · **Last Updated**: `2026-09-21` · **Difficulty**: `Beginner`

---

## TL;DR

Hash maps provide O(1) average-case key-value lookups using a hash function to map keys to bucket indices.

---

## 🔑 Complexity

| Operation | Average | Worst Case |
|-----------|---------|------------|
| Insert    | O(1)    | O(n)       |
| Lookup    | O(1)    | O(n)       |
| Delete    | O(1)    | O(n)       |
| Space     | O(n)    | O(n)       |
