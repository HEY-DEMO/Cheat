# Sorting Algorithms

> **Category**: `algorithms` · **Last Updated**: `2026-09-21` · **Difficulty**: `Intermediate`

---

## TL;DR

Choose your sorting algorithm based on data size, structure, and stability requirements. Quick Sort for general use, Merge Sort for stability, Counting Sort for bounded integers.

---

## 🔑 Comparison Table

| Algorithm      | Best     | Average  | Worst    | Space  | Stable |
|---------------|----------|----------|----------|--------|--------|
| Bubble Sort   | O(n)     | O(n²)    | O(n²)    | O(1)   | ✅     |
| Merge Sort    | O(n lg n)| O(n lg n)| O(n lg n)| O(n)   | ✅     |
| Quick Sort    | O(n lg n)| O(n lg n)| O(n²)    | O(lg n)| ❌     |
| Heap Sort     | O(n lg n)| O(n lg n)| O(n lg n)| O(1)   | ❌     |
| Counting Sort | O(n+k)   | O(n+k)   | O(n+k)   | O(k)   | ✅     |
