# Docker

> **Category**: `devops` · **Last Updated**: `2026-09-21` · **Difficulty**: `Intermediate`

---

## TL;DR

Docker packages applications into lightweight, portable containers that run consistently across environments. Learn images, containers, volumes, and networking.

---

## 🔑 Essential Commands

| Command                                | Description                          |
|----------------------------------------|--------------------------------------|
| `docker build -t app .`              | Build image from Dockerfile          |
| `docker run -d -p 8080:80 app`       | Run container in detached mode       |
| `docker ps`                            | List running containers              |
| `docker logs <id>`                    | View container logs                  |
| `docker compose up -d`               | Start multi-container app            |
| `docker system prune -a`             | Clean up unused resources            |
